Notation Key

🔴 Primary Key (PK)

Uniquely identifies each record in the entity. Shown above the PK separator line.

🔵 Foreign Key (FK)

References the PK of another entity. Creates a relationship link between tables.

🟠 PK + FK

Column serves as both a primary key component and a foreign key (composite PK in LINE).

‖ One (Mandatory)

Double bar — each instance must have exactly one matching record on the other side.

≺ Crow's Foot (Many)

Fork symbol — one record on the single side maps to many records on the crow's foot side.

PK Separator

The bold horizontal line inside each entity box separates PK attributes from non-key attributes.
