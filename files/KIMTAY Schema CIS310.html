Entity-Relationship Overview 5 Tables

The KIMTAY database models a pet supply company's sales operations. It tracks sales representatives, customers, inventory items, invoices, and invoice line items.

  • SALES_REP → CUSTOMER  (one rep manages many customers via REP_ID)
  • CUSTOMER → INVOICES  (one customer has many invoices via CUST_ID)
  • INVOICES → INVOICE_LINE  (one invoice has many line items via INVOICE_NUM)
  • ITEM → INVOICE_LINE  (one item appears on many line items via ITEM_ID)

SQL CREATE Script
-- ══ KIMTAY Database Schema (SQL Server) ══ BEGIN TRANSACTION; -- SALES_REP CREATE TABLE SALES_REP ( REP_ID CHAR(2) PRIMARY KEY, FIRST_NAME VARCHAR(20), LAST_NAME VARCHAR(20), ADDRESS VARCHAR(20), CITY VARCHAR(15), STATE CHAR(2), POSTAL CHAR(5), CELL_PHONE CHAR(12), COMMISSION DECIMAL(7,2), RATE DECIMAL(3,2) ); -- CUSTOMER CREATE TABLE CUSTOMER ( CUST_ID CHAR(3) PRIMARY KEY, FIRST_NAME VARCHAR(20), LAST_NAME VARCHAR(20), ADDRESS VARCHAR(20), CITY VARCHAR(15), STATE CHAR(2), POSTAL CHAR(5), EMAIL VARCHAR(30), BALANCE DECIMAL(7,2), CREDIT_LIMIT DECIMAL(7,2), REP_ID CHAR(2) -- FK → SALES_REP ); -- ITEM CREATE TABLE ITEM ( ITEM_ID CHAR(4) PRIMARY KEY, DESCRIPTION VARCHAR(30), ON_HAND NUMERIC, CATEGORY CHAR(3), LOCATION CHAR(1), PRICE DECIMAL(7,2) ); -- INVOICES CREATE TABLE INVOICES ( INVOICE_NUM CHAR(5) PRIMARY KEY, INVOICE_DATE DATE, CUST_ID CHAR(3) -- FK → CUSTOMER ); -- INVOICE_LINE (composite PK) CREATE TABLE INVOICE_LINE ( INVOICE_NUM CHAR(5), ITEM_ID CHAR(4), QUANTITY NUMERIC, QUOTED_PRICE DECIMAL(7,2), PRIMARY KEY (INVOICE_NUM, ITEM_ID) ); COMMIT TRANSACTION;
